Predictions describe the next sample if the participant continues. Position and quality are predicted separately, so the diamond need not lie on the landscape. The predicted action describes whether the participant will stop or continue; it is not a recommendation. The stopping probability is an uncalibrated model estimate. The cutoff maximizes F1 for this game in the saved validation results. Stopping includes submission and timeout. Previous position error compares the forecast made one step earlier with the latest revealed decision, in percentage points (pp).

Playback advances one decision per second, not at the original speed. The graph shows this participant's own samples; shared information is not yet visualized. The model uses the original shared-information features, although the graph displays own samples only.
